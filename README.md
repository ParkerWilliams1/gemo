# Gemo

**Gemo** is a college-exclusive video chat app designed to help students connect, collaborate, and build community in a secure, real-time environment.

---

## Overview

Gemo was created to make it easier for students to engage with peers—whether for academic study sessions, casual hangouts, or networking—while ensuring only verified college users can access the platform.

---

## Features

- **Real-Time Video Chat**  
  High-quality, low-latency video communication between verified users.

- **Student-Only Access**  
  Secure authentication ensures only college students can join and connect.

- **Study & Social Spaces**  
  Choose between collaborative workspaces and casual chat zones.

## Tech Stack

- **Flutter** – Frontend mobile framework  
- **Firebase** – Authentication & backend services  
- **VideoSDK** – Real-time video communication  
- **Provider / Riverpod** – State management  
- **Dart** – Core programming language

---

## Why Gemo?

Built with the goal of enhancing student life, Gemo provides a focused, safe, and flexible way for students to interact beyond the classroom. Unlike public video chat platforms, Gemo prioritizes user trust, simplicity, and campus exclusivity.
